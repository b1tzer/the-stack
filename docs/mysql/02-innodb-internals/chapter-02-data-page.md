# 数据页与行格式

## 1. 数据页结构 (16KB)

```
┌─────────────────┐
│ File Header     │  38字节
├─────────────────┤
│ Page Header     │  56字节
├─────────────────┤
│ Infimum/Supremum│  26字节
├─────────────────┤
│ User Records    │  用户记录
├─────────────────┤
│ Free Space      │  空闲空间
├─────────────────┤
│ Page Directory  │  页目录
├─────────────────┤
│ File Trailer    │  8字节
└─────────────────┘
```

## 2. 行格式

### 2.1 Compact 格式
```
┌─────────────────┐
│ 变长字段长度列表 │
├─────────────────┤
│ NULL 标志位      │
├─────────────────┤
│ 记录头信息       │  5字节
├─────────────────┤
│ 隐藏列          │  DB_ROW_ID/DB_TRX_ID/DB_ROLL_PTR
├─────────────────┤
│ 用户数据         │
└─────────────────┘
```

### 2.2 Dynamic 格式 (默认)
- 与 Compact 类似
- 大字段完全溢出，只存 20 字节指针

## 3. 页分裂

当页满时插入新记录，会发生页分裂：
1. 申请新页
2. 将一半记录移到新页
3. 更新指针

## 4. 页内记录管理

**记录在页内的组织方式：**
```
Infimum → 记录1 → 记录2 → ... → 记录N → Supremum
         （按主键顺序通过 next_record 指针串联）
```

- **Infimum**：页内最小记录，虚拟记录，始终存在
- **Supremum**：页内最大记录，虚拟记录，始终存在
- 所有用户记录通过单向链表连接，按主键顺序排列

**Page Directory（页目录）：**
- 将记录分组（每组 4-8 条记录）
- 存储每组最后一条记录的偏移量
- 用于页内二分查找，加速记录定位

## 5. 页的状态与类型

| 页类型 | 说明 |
|--------|------|
| FIL_PAGE_INDEX | B+ 树索引页 |
| FIL_PAGE_UNDO_LOG | Undo Log 页 |
| FIL_PAGE_INODE | 索引节点页 |
| FIL_PAGE_IBUF_FREE_LIST | Change Buffer 空闲列表 |
| FIL_PAGE_TYPE_ALLOCATED | 已分配但未使用 |

## 6. 行溢出处理

当一行数据超过页大小的一半（约 8KB）时，会发生行溢出。

**Compact 格式：**
- 大字段前 768 字节存储在当前页
- 剩余数据存储在溢出页（overflow page）
- 通过指针指向溢出页

**Dynamic 格式（MySQL 5.7+ 默认）：**
- 大字段只存储 20 字节指针
- 所有数据都在溢出页
- 当前页可以容纳更多行

```sql
-- 查看表使用的行格式
SELECT table_name, row_format FROM information_schema.tables
WHERE table_schema = 'mydb';

-- 修改行格式
ALTER TABLE users ROW_FORMAT=DYNAMIC;
```

## 7. 页分裂详解

**触发条件：**
- 页的可用空间不足以插入新记录
- 通常发生在随机插入（如 UUID 主键）

**分裂过程：**
```
1. 原页 [1,3,5,7,9] 要插入 6
2. 申请新页
3. 将后半部分移到新页：原页 [1,3,5] + 新页 [6,7,9]
4. 更新父节点指针
```

**页分裂的影响：**
- 产生随机 IO（新页可能在磁盘任意位置）
- 页空间利用率下降（约 50%）
- 索引树可能增高

```sql
-- 查看页分裂情况
SHOW ENGINE INNODB STATUS;  -- 在 INSERT BUFFER AND ADAPTIVE HASH INDEX 部分
```

## 8. 最佳实践

1. **使用顺序主键**（AUTO_INCREMENT）避免页分裂
2. **避免 UUID 作为主键** — 随机写入导致频繁页分裂
3. **使用 DYNAMIC 行格式** — 避免大字段导致行溢出
4. **控制单行数据大小** — 尽量不超过 8KB
5. **TEXT/BLOB 列单独拆表** — 减少主表的行溢出概率
