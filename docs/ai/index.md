# AI 工程知识库

本页负责选择入口。Agent 的定义、存在原因和完整学习地图见[第一篇导论](./01-导论.md)。

## 按顺序学习

1. [导论：什么是 AI Agent，这条路怎么走](./01-导论.md)——先建立整体地图，知道自己站在哪一环。
2. [LLM 接口与提示词工程](./02-LLM接口与提示词工程.md)——先把模型调用和输出稳定性做扎实，这是后面一切能力的地基。
3. [RAG 架构与工程落地](./03-RAG架构与工程落地.md)与 [Function Calling 与 Agent 范式](./04-FunctionCalling与Agent范式.md)——两条主线：让模型用上私有知识，让模型调用工具。
4. [框架化开发：Python 三件套](./05-框架化开发-Python三件套.md)与 [MCP 协议与工具生态](./06-MCP协议与工具生态.md)——从手写循环过渡到框架与标准协议。
5. [Agent 编排与状态持久化](./07-Agent编排与状态持久化.md)与 [Memory 长期记忆](./08-Memory长期记忆.md)——解决复杂任务的拆分、断点续跑和跨会话记忆。
6. [端到端实战：从 0 到 1 搭一个生产 Agent](./11-端到端实战.md)——把前面的能力串成一个可上线的系统。

## 从问题进入

| 你现在的问题 | 入口 |
| :-- | :-- |
| 模型输出不稳定或提示词难以维护 | [LLM 接口与提示词工程](./02-LLM接口与提示词工程.md) |
| 要让模型使用私有知识 | [RAG 架构与工程落地](./03-RAG架构与工程落地.md) |
| 要让模型调用工具并执行任务 | [Function Calling 与 Agent 范式](./04-FunctionCalling与Agent范式.md) |
| 不想用裸 SDK 手写循环 | [框架化开发：Python 三件套](./05-框架化开发-Python三件套.md) |
| 工具接入方式不统一，难以复用 | [MCP 协议与工具生态](./06-MCP协议与工具生态.md) |
| 要组织多步流程、状态和长期记忆 | [Agent 编排](./07-Agent编排与状态持久化.md)，再到 [Memory 长期记忆](./08-Memory长期记忆.md) |
| 上线前不知道效果好不好、出了问题查不到 | [评估与可观测性](./09-评估与可观测性.md) |
| 担心越权调用、提示词注入和敏感数据泄露 | [安全护栏](./10-安全护栏.md) |
| 想先完整跑通一个项目 | [端到端实战](./11-端到端实战.md) |

## 内容边界

模型接口、框架和协议变化较快。示例以正文标注的适用版本或时间为范围；生产升级前核对对应官方文档和发布说明。组件级机制放在各自专题，跨组件业务方案放在[场景实战](../scenarios/index.md)。
