# 值、变量与类型

本页面向刚跑通第一个程序的读者，回答三个问题：Python 里的值有哪些类型，变量到底是什么，程序是怎么执行的。这是后面条件循环、容器、函数各章的基础。

## 1. 值有类型

你在程序里写下的每一个值，都属于某种"类型"。类型决定了这个值是什么、能做什么：

```python
1          # int 整数
3.14       # float 浮点数
'hello'    # str 字符串
True       # bool 布尔值
```

`type()` 可以查看一个值的类型：

```python
type(1)       # <class 'int'>
type(3.14)    # <class 'float'>
type('hello') # <class 'str'>
```

不同类型能做不同的事：整数能相加，字符串能拼接，但整数和字符串不能混在一起相加（这一点在第 6 节会再讲）。理解"值有类型"，是理解后面所有章节的前提。

## 2. 变量是名字，不是盒子

很多人初学编程时，会把变量理解成"一个盒子，里面装着一个值"。Python 里更准确的理解是：变量是一个**名字**，它**指向**某个值。

```python
a = 1
print(a)        # 1
a = 'hello'
print(a)        # hello
```

`a = 1` 的意思是"把名字 `a` 指向整数 `1`"；`a = 'hello'` 让 `a` 改指向字符串 `'hello'`。名字本身没有固定的类型，类型属于它指向的那个值。这个理解在后面讲容器和拷贝时会反复用到。

## 3. 数值类型与运算

### 3.1 int 没有大小上限

Python 的整数是"任意精度"的，没有固定的大小上限，只受内存限制：

```python
print(2 ** 100)
# 1267650600228229401496703205376
```

`2 ** 100` 是 2 的 100 次方，结果是一个 31 位的巨大整数，直接就能算出来，不存在"整数溢出"的问题。

### 3.2 bool 是 int 的特殊子类

布尔值只有两个：`True` 和 `False`。在 Python 里，`bool` 是 `int` 的子类：

```python
True == 1                # True
isinstance(True, int)    # True
True + 1                 # 2
```

所以 `True` 能和整数一起做运算，`True + 1` 等于 `2`。这个特性日常不该依赖，但了解它有助于理解为什么有些条件表达式里 `1` 和 `True` 会互换。

### 3.3 除法与取模：最容易写错的一处

Python 里有两个除法运算符，语义不同：

- `/` 永远返回浮点数，即使两个操作数都是整数。
- `//` 是"向下取整"的整除，结果向负无穷方向取整。
- `%` 是取模，结果的符号跟随除数（而不是被除数）。

```python
10 / 4     # 2.5
10 // 4    # 2
-7 // 3    # -3   向下取整，而不是向零取整
-7 % 3     # 2    结果符号跟随除数
```

`-7 // 3` 的结果是 `-3`（而不是 `-2`），因为 `//` 向下取整：`-7 / 3` 约等于 `-2.33`，向下取整得到 `-3`。`//` 和 `%` 保证一个恒等式永远成立：

```txt
a == (a // b) * b + (a % b)
```

代入 `a = -7, b = 3`：`-7 == (-3) * 3 + 2`，成立。

### 3.4 运算符与优先级

算术运算符有 `+ - * / // % **`。其中 `**`（幂）优先级最高，且是右结合的。不需要记忆全部优先级时，用括号显式表达意图——括号里的先算，可读性也更好。

## 4. 字符串与格式化

`str` 是字符串类型，用单引号或双引号表示，两者等价。字符串是不可变的（创建后不能改，但可以基于它生成新字符串）。

### 4.1 f-string 是首选格式化方式

把变量的值嵌入字符串，最推荐用 f-string：在字符串前加 `f`，用 `{}` 把表达式包起来：

```python
name = 'Python'
print(f'hello {name}, {22 / 7:.2f}')
# hello Python, 3.14
```

`{name}` 会被替换成变量 `name` 的值；`{22 / 7:.2f}` 里，`22 / 7` 是表达式，`: .2f` 表示保留两位小数的浮点格式。f-string 在运行前求值，嵌入的表达式必须合法，否则抛 `SyntaxError`。

### 4.2 字符串方法与切片

常用方法：`upper()`、`lower()` 转大小写，`strip()` 去掉首尾空白，`split()` 按分隔符拆分，`join()` 拼接，`replace()` 替换。

切片用 `s[start:end]` 取子串，区间左闭右开（包含 `start`，不包含 `end`）：

```python
s = 'hello'
s[1:4]      # 'ell'
s[::-1]     # 'olleh'  步长为 -1 时反转
```

字符串不可变，所有方法都返回新字符串，不修改原对象。

### 4.3 文本和字节：str 与 bytes

Python 区分两种"字符串"：`str` 存文本（Unicode 字符），`bytes` 存原始字节。两者必须通过编码/解码显式转换，不能混用：

```python
s = '中文'
len(s)                    # 2  两个字符
b = s.encode('utf-8')     # str → bytes
len(b)                    # 6  每个汉字在 UTF-8 里占 3 字节
b.decode('utf-8')         # bytes → str，得到 '中文'
```

实务要点：

- 读写文件、网络收发时，永远在边界处做 `encode`/`decode`，程序内部统一用 `str`。
- 不指定编码时，`open` 和网络库使用平台默认编码，中文环境可能不一致，显式写 `encoding='utf-8'` 更稳。
- `bytes` 和 `str` 之间做 `+` 或比较会抛 `TypeError`，这是编码混乱最常见的报错信号。

## 5. 输入输出与类型转换

`input()` 读取一行标准输入，**永远返回 `str`**；`print()` 输出到屏幕。要拿到数字，必须先把字符串转成数字：

```python
s = input('输入一个数: ')   # 返回 str
n = int(s)                  # 转 int；输入不是数字时抛 ValueError
print(n * n)
```

`int()`、`float()`、`str()` 完成常用转换。注意 `int('42')` 返回 `42`，但 `int('4.2')` 会抛 `ValueError`——`int` 不接受带小数点的字符串，需要先 `float('4.2')` 再转 `int`。

## 6. 程序如何执行

你写的源码不是被"读一行执行一行"的。Python 会先把整个源码编译成一种中间形式（字节码），再逐条执行。语法错误（`SyntaxError`）会在编译这一步就报出来。

但 Python 不在运行前检查所有类型错误。类型相关的问题要等程序真正运行到那一行才暴露：

```python
x = 1
x + 'a'   # TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

这段代码能通过编译，运行到 `x + 'a'` 才抛 `TypeError`——因为整数和字符串不能直接相加。这正是第 1 节说的"不同类型能做不同的事"。

这带来两个实际后果：

- 反馈很快：改完直接 `python3 script.py` 就能跑，不用等待漫长的编译。
- 更依赖测试：类型错误不会被提前拦住，要靠写测试来兜底。这正是工程化章节要讲测试的原因。

## 7. 这一章要记住的结论

值有类型，类型决定值能做什么；变量是绑定到值的名字，名字本身没有类型。`int` 任意精度、`bool` 是 `int` 子类；`/` 恒返回 `float`，`//` 和 `%` 向下取整。字符串用 f-string 格式化、用切片取子串；`input()` 恒返回 `str`，数字要先转换类型。Python 执行前先编译到字节码，但类型错误留到运行时。
