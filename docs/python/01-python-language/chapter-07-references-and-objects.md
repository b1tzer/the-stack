# 引用与对象模型

本页面向已经学完类与对象的读者，把前面分散提到的"对象、引用、身份"串起来，回答三个问题：为什么说 Python 里一切皆对象，`==` 和 `is` 到底差在哪，函数怎么也能当值用。这是把零散直觉收敛成统一心智模型的一章。

## 1. 一切皆对象

前面各章你已经见过：整数、字符串、列表、字典、函数、类，都是对象。`type()` 返回一个对象的类型：

```python
type(1)     # <class 'int'>
type('x')   # <class 'str'>
type([])    # <class 'list'>
type(len)   # <class 'builtin_function_or_method'>
```

连内置函数 `len` 都是一个对象。这意味着函数可以像值一样被传递、被放进列表、被当作参数——这个特性叫"函数是一等公民"，在装饰器和回调里会反复用到。

"一切皆对象"的实用含义是：只要是对象，就能赋值给变量、放进容器、作为参数传递。你对"值"已有的操作，对函数、类同样适用。

## 2. 对象的身份：`==` 与 `is`

两个内容相同的对象，可能是同一个对象，也可能是两个各自独立的对象。`==` 判断"值是否相等"，`is` 判断"是不是同一个对象"：

```python
x = [1, 2]
y = [1, 2]
print(x == y)   # True  值相等
print(x is y)   # False 不是同一个对象
```

`x` 和 `y` 各自指向一个内容相同的列表，所以 `==` 为 `True`；但它们是两个不同的列表对象，所以 `is` 为 `False`。

日常比较值一律用 `==`。`is` 只在少数场景使用，最典型的是判断一个值是不是 `None`：

```python
if result is None:
    print('没有结果')
```

不要用 `is` 比较整数或字符串的值——对这类不可变对象，`is` 的结果取决于解释器是否复用了同一个对象，这个行为不可依赖。

## 3. 引用与共享

变量只是指向对象的名字，赋值复制的是引用，不是对象本身。[容器与可变性](./chapter-03-collections.md)里已经见过：两个名字指向同一个列表，改一个另一个也变。

这里补充两个容易忽略的点。

**不可变对象不会"被共享修改"**。整数、字符串不可变，两个名字指向同一个整数也没关系，因为谁也改不了它：

```python
a = 100
b = a
a = 200      # 让 a 指向新的整数 200，b 仍指向 100
print(b)     # 100
```

**参数传递也是传引用**。[函数、作用域与模块](./chapter-04-functions.md)里的结论：函数收到的是对象的引用，可以修改可变对象的内容，但不能让调用方的名字重新绑定。

理解"赋值复制引用"这一条，能解释 Python 里绝大部分"为什么改到了别处"的困惑。

## 4. 函数是一等公民

既然函数也是对象，它就能像值一样被传递和使用：

```python
def add(a, b):
    return a + b

def apply(fn, a, b):
    return fn(a, b)

apply(add, 1, 2)   # 3
```

`apply` 接收一个函数 `fn` 作为参数并调用它。这种"把函数当值传递"的能力，是[装饰器](./chapter-08-pythonic.md)和高阶函数的基础。

## 5. 这一章要记住的结论

Python 里一切皆对象，函数也是；`==` 比值、`is` 比身份，日常比较用 `==`，判断 `None` 用 `is`；赋值复制引用而非对象，不可变对象不会被"共享修改"，参数传递也是传引用；函数能当值传递，这是装饰器的基础。
