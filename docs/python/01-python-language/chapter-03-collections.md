# 容器与可变性

本页面向已经能写 Python、但对容器语义和可变性还拿不准的读者，回答三个问题：四种内置容器分别怎么用，可变与不可变有什么区别，赋值和拷贝为什么经常改到"不该改"的对象。这部分是 Python 最容易出错的地方，值得多花时间。

遍历与推导式依赖[条件与循环](./chapter-02-control-flow.md)里的 `for` 和可迭代对象；对象引用模型见[引用与对象模型](./chapter-07-references-and-objects.md)。

## 1. 四种内置容器

Python 有四种核心容器：

| 类型 | 特点 | 示例 |
| :-- | :-- | :-- |
| `list`（列表） | 有序、可变、可重复 | `[1, 2, 3]` |
| `tuple`（元组） | 有序、不可变 | `(1, 2, 3)` |
| `dict`（字典） | 键值对、键唯一 | `{'a': 1}` |
| `set`（集合） | 无序、元素唯一 | `{1, 2, 3}` |

列表、字典、集合是可变的（创建后能增删改）；元组不可变。字符串和数值也属于不可变类型。区分"可变"和"不可变"是理解第 6 节赋值与拷贝的关键。

## 2. 列表与切片

列表是使用最频繁的容器。创建、追加、索引：

```python
items = [1, 2, 3]
items.append(4)      # 原地修改，返回 None
items[0]             # 1
```

切片用 `items[start:end:step]` 取子序列，返回新列表，区间左闭右开：

```python
items = [0, 1, 2, 3, 4]
items[1:3]    # [1, 2]
items[::-1]   # [4, 3, 2, 1, 0]  反转
```

注意 `append` 这类原地修改的方法返回 `None`，不要写成 `items = items.append(4)`，那样 `items` 会变成 `None`。Python 里"返回新对象"和"原地修改"是两种不同的操作，`append` 属于后者。

## 3. 推导式

列表推导式用一条表达式从可迭代对象生成新列表，等价于 `for` 循环加 `append`，但更紧凑：

```python
[n * n for n in [1, 2, 3, 4] if n % 2 == 0]   # [4, 16]
```

读作：对列表里每个 `n`，如果 `n` 是偶数，算出 `n * n` 放进新列表。推导式可读性高，但嵌套过多时应改回普通循环。

## 4. 字典

字典是键值对的集合，键必须是可哈希（通常不可变）类型。取值用 `d[key]`，键不存在时抛 `KeyError`；用 `get` 提供默认值：

```python
d = {'a': 1, 'b': 2}
d['a']          # 1
d.get('z', 0)   # 0  键不存在返回默认值
list(d.items()) # [('a', 1), ('b', 2)]
```

字典也有推导式：

```python
{k: v * 10 for k, v in d.items()}   # {'a': 10, 'b': 20}
```

## 5. 集合

集合存放唯一元素，支持集合运算：

```python
{1, 2, 3} | {2, 3, 4}   # {1, 2, 3, 4}  并集
{1, 2, 3} - {2, 3, 4}   # {1}           差集
```

集合常用于去重和成员判断（`x in s`），平均 O(1) 查询。

## 6. 可变性、赋值与拷贝

这是容器章节最重要的部分。赋值复制的是引用，不是对象；多个名字可以指向同一个可变对象，改一处会处处可见。

```python
a = [1, 2, 3]
b = a            # b 指向同一个列表
b.append(4)
print(a)         # [1, 2, 3, 4]
```

想要独立副本，用浅拷贝 `a.copy()` 或切片 `a[:]`。浅拷贝只复制外层对象，内层可变对象仍共享：

```python
a = [1, [2, 3]]
b = a.copy()
b[1].append(4)
print(a)         # [1, [2, 3, 4]]  内层列表仍被共享
```

`a.copy()` 复制了外层列表，但内层的 `[2, 3]` 没有被复制，`b[1]` 和 `a[1]` 指向同一个内层列表，所以 `b[1].append(4)` 也影响到了 `a`。

需要完全独立的副本，用 `copy.deepcopy`：

```python
import copy
b = copy.deepcopy(a)
b[1].append(5)
print(a)         # [1, [2, 3, 4]]  不受影响
```

元组虽然不可变，但它持有的可变对象仍可被修改——不可变只作用于元组本身，不递归作用于元素。这些共享引用的坑，在[函数、作用域与模块](./chapter-04-functions.md)的可变默认参数里会再次出现。

## 7. 这一章要记住的结论

列表、字典、集合可变，元组和字符串不可变；赋值只复制引用，浅拷贝只复制外层。判断一个操作是否"改到了别处"，看它操作的对象是不是可变、是不是被多个名字共享。
