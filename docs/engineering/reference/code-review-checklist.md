# Code Review 速查

## 检查清单

### 正确性

- [ ] 逻辑是否正确，边界条件是否处理
- [ ] 空指针、数组越界等运行时异常
- [ ] 并发安全（共享变量、竞态条件）
- [ ] 事务边界是否正确
- [ ] 异常处理是否合理（不吞异常）

### 可读性

- [ ] 命名是否清晰（变量、方法、类）
- [ ] 方法是否过长（>50 行考虑拆分）
- [ ] 注释是否必要且准确
- [ ] 魔法数字是否提取为常量

### 设计

- [ ] 是否符合单一职责
- [ ] 是否有重复代码
- [ ] 依赖方向是否合理
- [ ] 接口设计是否简洁

### 安全

- [ ] SQL 注入风险
- [ ] XSS 风险
- [ ] 敏感信息是否硬编码
- [ ] 权限检查是否到位

### 性能

- [ ] N+1 查询问题
- [ ] 不必要的数据库查询
- [ ] 大对象是否及时释放
- [ ] 缓存使用是否合理

## Review 原则

- 对事不对人，讨论代码而非作者
- 提出问题时给出建议或示例
- 区分"必须改"和"建议改"
- 及时 review，不要堆积
