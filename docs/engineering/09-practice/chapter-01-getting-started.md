# 软件工程入门

> 从零理解软件工程的核心概念。

## 什么是软件工程

软件工程 = 用系统化、可量化的方法开发和维护软件。

核心目标：**按时、按质、按预算交付有价值的软件**。

## 工程 vs 编程

| 维度 | 编程 | 软件工程 |
|------|------|----------|
| 范围 | 写代码 | 需求→设计→编码→测试→部署→维护 |
| 关注点 | 功能实现 | 质量、可维护性、团队协作 |
| 时间尺度 | 小时/天 | 月/年 |
| 产出 | 程序 | 产品 |

## 核心实践

1. **版本控制**：Git 管理代码，每次变更可追溯
2. **代码审查**：同事互审，减少缺陷，传播知识
3. **自动化测试**：单元测试、集成测试、端到端测试
4. **持续集成**：代码提交后自动构建和测试
5. **持续部署**：通过流水线自动发布到生产环境
6. **监控运维**：线上问题快速发现和定位

## 学习路径

```text
基础：设计原则 → 设计模式 → 重构
架构：架构风格 → DDD → 系统设计
实践：Git 工作流 → CI/CD → 测试 → 可观测性
安全：认证授权 → 常见攻击 → 安全编码
```
